| Family | File(s) | Source / licence |
|---|---|---|

Reference storefronts use commercial/unknown-licence families (IRANYekan, IRANSans, YekanBakh, Dana, Rokh …). Those are NOT bundled;
the closest licensed substitute per template is documented in `docs/design-references/v5-six-sites/FONT_SUBSTITUTIONS.md`.
