# راهنمای QA ویندوز — هدر/فوتر در Inspector، هدر حرفه‌ای مستقل، عرض صفحات (۱۴۰۵/۰۸/۱۰)

> این راهنما فرض می‌کند کد پس از **مجوز Push جداگانه** و `git fetch` توسط خودتان در Worktree ویندوز آمده است. هیچ تغییری در پورت ۸۰۰۸ / دیتابیس QA فعلی / Production داده نشده. هیچ Migration وجود ندارد (دستورِ `migrate` لازم نیست). همهٔ آزمایش‌ها فقط روی **Draft** هستند؛ تا «انتشار» نزنید فروشگاه عمومی تغییر نمی‌کند.

آدرس Studio: `http://rasti-mode-demo.rastisi.localhost:8008/admin-portal/vision-studio/` (قالب را از «قالب‌ها ← تغییر قالب» عوض کنید.)

## ۱. کلیک روی هدر/فوتر (بدون پنجرهٔ بزرگ)
| کار | انتظار |
|---|---|
| قالب «آتلیه دوپنل» را اعمال کنید → روی هدر داخل Canvas کلیک کنید | پنجرهٔ بزرگ و تیره **باز نمی‌شود**. کنار Canvas یک Inspector «سربرگ (هدر)» با تب‌های «مدل‌ها / محتوا و نمایش / پیشرفته» باز می‌شود؛ Canvas هنوز دیده و کلیک‌پذیر است |
| روی فوتر کلیک کنید (وقتی Inspector هدر باز است) | Inspector به «پابرگ (فوتر)» عوض می‌شود (تب «طراحی» هم دارد) |
| کلید Esc / دکمهٔ «بستن» / «انجام شد» | Inspector بسته می‌شود |
| ←/→ روی تب‌ها (فارسی: ← = تب بعدی)، Home/End، Tab | تب‌ها جابه‌جا می‌شوند، فوکوس روی تب می‌ماند؛ Tab در Inspector گیر نمی‌کند |

## ۲. مدل هدر و فوتر
1. در تب «مدل‌ها»، کارت‌ها تصویر واقعی دارند؛ «مدل فعلی» علامت دارد و اول لیست است.
2. «انتخاب این مدل» روی مدل دیگر → همان لحظه در Canvas عوض می‌شود، نوار «پیش‌نویس ذخیره شد» می‌آید.
3. «بازگرداندن» (Undo) بالای صفحه → مدل قبلی برمی‌گردد و **Inspector بعد از بارگذاری دوباره باز می‌ماند**؛ «ازنو» (Redo) هم همین‌طور.
4. «مشاهدهٔ بزرگ‌تر» فقط نمایش است و چیزی را تغییر نمی‌دهد.
5. کنترل: فقط یک هدر در صفحه باشد؛ Hero، متن/تصاویر، منو، لوگو، شمارهٔ تماس و فوتر تغییر نکنند. تغییر فوتر هم هدر/هیرو را تغییر ندهد.
6. «پیش‌نمایش» (تب جدید) Draft را نشان می‌دهد؛ «انتشار» را فقط اگر عمداً می‌خواهید بزنید.

## ۳. هدر حرفه‌ای چهار قالب روی هر قالب
در تب «مدل‌ها» بالای کارت‌ها دو بخش هست:
- **جایگاه هدر در صفحهٔ اصلی**: بالای صفحه (مستقل) / داخل بوم هیرو / شناور روی تصویر.
- **هدرهای حرفه‌ای آماده**: آتلیه دوپنل، نشریهٔ نوآر، تجارت شیشه‌ای، بوم نامتقارن.

| قالب فعلی | کار | انتظار |
|---|---|---|
| یکی از ۴ قالب هیروی یکپارچه | «بالای صفحه (مستقل)» | هدر از داخل بوم بیرون می‌آید، **یک هدر**، هیرو کامل؛ Undo برمی‌گرداند |
| همان | «اعمال» روی «بوم نامتقارن» | مدل `floating_compact` + هدر شناور روی تصویر |
| قالب بدون «بوم هدر و هیرو» (مثلاً «استریت دراپ») | نگاه به بخش جایگاه | دو گزینهٔ «داخل بوم هیرو» و «شناور» غیرفعال با توضیح فارسی |
| همان | «اعمال مدل» روی هر Recipe | فقط **مدل** هدر عوض می‌شود، هیچ بخشی اضافه/حذف نمی‌شود، یک هدر؛ پیام «مدل هدر اعمال شد؛ چون بالای صفحه بوم هدر و هیرو نیست…» |

## ۴. عرض صفحات
تب «طراحی» ← «چیدمان و عرض صفحات»:
| انتخاب | انتظار (در Preview) |
|---|---|
| استاندارد (پیش‌فرض / Storeهای قبلی) | دقیقاً مثل قبل |
| عریض | محتوا روی مانیتور بزرگ پهن‌تر |
| تمام‌عرض | محتوا تقریباً تا لبه‌ها، با فاصلهٔ کناری؛ متن/کارت‌ها به لبهٔ مانیتور نمی‌چسبند |
| سفارشی + «حداکثر عرض محتوا» + «فاصلهٔ کنارهٔ صفحه» | ستون محتوا دقیقاً همان عدد؛ عدد خارج از ۹۶۰–۲۴۰۰ یا Gutter خارج از ۸–۶۴ → پیام فارسی و **ذخیره نمی‌شود** |

بررسی در DevTools (Responsive) روی **۳۲۰، ۳۹۰، ۷۶۸، ۱۰۲۴، ۱۳۶۶، ۱۴۴۰، ۱۹۲۰**، صفحه‌ها: خانه، لیست محصولات/جست‌وجو، جزئیات محصول، Collection، سبد، پرداخت، فوتر:
- اسکرول افقی نباشد؛ قیمت و «تومان» یک خط بماند؛ نسبت تصویر کارت‌ها نشکند.
- Undo/Redo عرض را برمی‌گرداند؛ تا «انتشار» نزنید سایت عمومی تغییر نمی‌کند؛ بعد از «انتشار» همهٔ صفحه‌ها همان عرض را دارند.
- بعد از عوض‌کردن قالب، انتخاب عرض حفظ می‌شود.
- Storeای که این بخش را هرگز لمس نکرده شکل قبلی را دارد.
