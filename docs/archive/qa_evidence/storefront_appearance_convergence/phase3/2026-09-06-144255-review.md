# Brand-scoped CSS fix: shared sheet now mirrors Home's effective cascade (48px), not the stale first block (40px)

Scoped re-review of the fix for the prior CRITICAL finding in Task 3. The earlier attempt copied home.css's FIRST `.brand-*` block (max-height:40px, radius:12px, background:var(--card)) into `storefront_builder.css`. Because that sheet loads AFTER home.css on the Home envelope and home.css has a LATER "dense" block (48px, radius:6px, #fff, min-height:72px) that wins on Home by source order, the appended first-block rules overrode Home's dense block and shrank Home's logos 48px→40px — violating the "Home unchanged" constraint. The fix rewrites the appended block to carry Home's per-property EFFECTIVE (cascade-resolved) values, so the shared sheet overriding home.css on Home is a no-op while non-Home envelopes (which never load home.css) get the same correct presentation.

Watch for: nothing blocking. The appended block matches Home's effective cascade property-for-property (confirmed), the test now asserts 48px with a dedicated Home-unchanged guard (confirmed), and home.css has zero diff (confirmed). The fix is uncommitted in the working tree, so it must be committed before shipping.

**Verdict**: APPROVED

## High-level view

The appended `.brand-*` block in `storefront_builder.css` (lines 4473–4493) now reproduces the value that actually governs Home for every property: where both home.css blocks set a property, the shared sheet uses the dense/later value; where only the first block sets it, the shared sheet uses that first-block value. Every property was cross-checked against both home.css blocks and matches Home's effective cascade, so the override on Home resolves to identical pixels.

The test finding is resolved. `test_brand_logo_max_height_matches_home_css` asserts `max-height:48px` and explicitly `assertNotIn("max-height:40px")`. A new guard, `test_brand_shared_rules_are_noop_over_home_effective_cascade`, asserts the shared sheet mirrors home.css's dense governing values (48px, min-height:72px, radius 6px, #fff, gap 9px, flex 150px). `test_home_css_brand_rules_are_not_deleted` still asserts home.css retains its original rules including the 40px first block, so home.css is not deleted or edited.

Scope is clean: all five appended selectors are `.brand-`-anchored (no global spill), the scope-audit test enforces this via a marker comment, and home.css shows no diff against HEAD.

### Per-property cascade equality between the shared block and Home's effective values

Home's effective cascade is the union of home.css's early block (lines 246–250) and dense block (lines 336–340), with the dense value winning wherever both set a property. Cross-checking the appended `storefront_builder.css` block (lines 4489–4493) property by property (confirmed by reading all three blocks):

```
.brand-tile
  display/align-items/justify-center   first-only  → flex/center/center      shared: flex/center/center      ✓
  padding      early 16px / dense 10px  both        → 10px (dense)            shared: 10px                    ✓
  border       first-only               → 1px solid var(--line)               shared: 1px solid var(--line)   ✓
  border-radius early 12px / dense 6px   both        → 6px (dense)             shared: 6px                     ✓
  background   early var(--card)/dense #fff both     → #fff (dense)            shared: #fff                    ✓
  min-height   dense-only 72px          → 72px                                shared: 72px                    ✓

.brand-tile img
  max-height   early 40px / dense 48px   both        → 48px (dense)            shared: 48px                    ✓
  max-width / object-fit  first-only     → 100% / contain                     shared: 100% / contain          ✓

.brand-tile-name
  font-size    early 13px / dense 11px   both        → 11px (dense)            shared: 11px                    ✓
  font-weight  early 700 / dense 600     both        → 600 (dense)             shared: 600                     ✓
  color        dense-only #444          → #444                                shared: #444                    ✓

.brand-carousel
  display/overflow-x/scroll-snap-type/-webkit-overflow-scrolling  first-only → flex/auto/x mandatory/touch    shared: same  ✓
  gap          early 14px / dense 9px    both        → 9px (dense)             shared: 9px                     ✓
  padding-bottom early 6px / dense 4px   both        → 4px (dense)             shared: 4px                     ✓

.brand-carousel .brand-tile
  flex         early 0 0 140px / dense 0 0 150px  both → 0 0 150px (dense)     shared: 0 0 150px               ✓
  scroll-snap-align  first-only          → start                              shared: start                   ✓
```

Every property that both home.css blocks set carries the dense value in the shared sheet; every first-block-only property carries the first-block value; dense-only `min-height:72px` is carried. Since the shared sheet's selectors have identical specificity to home.css's and load later, applying them on Home resolves to the exact values home.css already produces — a genuine no-op. The prior regression (40px, radius 12px, var(--card)) is gone; `max-height:40px` no longer appears anywhere in the shared sheet.

### Test now asserts the effective value and guards Home-unchanged

`test_brand_logo_max_height_matches_home_css` asserts `max-height:48px` and `object-fit:contain` present and `max-height:40px` absent — the stale first-block value that caused the regression can no longer slip back in. The new `test_brand_shared_rules_are_noop_over_home_effective_cascade` reads both stylesheets, asserts home.css's dense block literally contains `.brand-tile img{max-height:48px}` (the block that wins on Home), and asserts the shared sheet mirrors the full set of governing dense values: `max-height:48px`, `min-height:72px`, `border-radius:6px`, `background:#fff`, `gap:9px`, `flex:0 0 150px`. This is the correct anchor: it ties the assertion to the value that actually governs Home rather than a hardcoded constant, so a future edit to either sheet that breaks the no-op fails the test.

`test_home_css_brand_rules_are_not_deleted` still asserts home.css contains `.brand-tile`, `.brand-carousel`, and `.brand-tile img{max-height:40px` — proving the fix added to the shared sheet without stripping Home's own rules. home.css shows zero diff against HEAD, consistent with this.
