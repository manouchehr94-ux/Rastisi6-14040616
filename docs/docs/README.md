# Project documentation

Official project documentation.

The canonical architecture documentation is the **Architecture Knowledge System**
under [`docs/architecture_knowledge_system/`](../architecture_knowledge_system/)
(start at [`00_GOVERNING_RULES_AND_PHASE1.md`](../architecture_knowledge_system/00_GOVERNING_RULES_AND_PHASE1.md)).

Protected canonical product documents remain under `product/` (for example the
merchant/admin implementation and product-management reports). Historical product,
storefront, and prototype-gap reports previously under this tree have been relocated
to [`docs/archive/docs/product/`](../archive/docs/product/) as preserved historical
evidence.
