# گزارش اصلاح مستقل زیرساخت انتشار RastiSi

مبنا: `cd7b66837bf63bd2a0f5e4d53c80cb3964e6480f`، مربوط به PR #46.
شاخهٔ مستقل: `codex/cicd-safety-20261112`.

هیچ Push، Merge، تغییر تنظیمات GitHub یا اتصال به Production انجام نشد.
هیچ فایل برنامه، مدل یا منطق پرداخت/سفارش/اشتراک و هیچ وابستگی برنامه تغییر نکرد.
همهٔ دیتابیس‌ها، کلیدهای SSH و داده‌های آزمون محلی و ساختگی بودند.

۱۲ سناریوی اجباری مأموریت در این تست‌ها پوشش دارند: alias/unknown migration،
قطع هنگام migration، Rollback با marker، شکست غیراتمیک، نصب ایزوله، backup/drill،
قطع SSH، انتشار هم‌زمان، health failure، Python mismatch، حفظ داده پس از Rollback
و رد تشخیص خطای جدید در شناسهٔ Known Failure قبلی. تست TLS واقعی نیز موفق است.

تست‌های برنامهٔ واقعی از commitهای تاریخی و ابزارهای همین working tree استفاده
کردند؛ این تست‌ها اجرای server واقعی، systemd واقعی یا GitHub environment approval
نیستند. سرویس برنامه در rehearsal با مدیر فرایند آزمایشی جایگزین systemd شده است.
در آزمون SSH نصب‌شده، transport/حساب/sudo واقعی‌اند ولی برنامه و systemctl stub هستند.
این مرزها به‌معنای آزمایش Production نیستند.

## موانع باقی‌مانده

۱. هشدارهای امنیتی Pillow/cryptography: [ارزیابی امنیتی](DEPENDENCY_SECURITY_REVIEW.md).
ارتقای major بدون تست جداگانه یا تأیید کلی استثناها انجام نشد.

۲. refund_failed: تست مستقل notifications بازتولید شد؛ اعلان شکست نهایی refund
با وضعیت فعلی کد هم‌خوان نیست. منطق مالی دست‌نخورده است و این نقص معاف نشده است.

۳. دو تست تازهٔ فروشگاه‌ساز: BackgroundCapabilityProjectionTests و
SchemaEnablementRegistryGuardTests در test_r4_settings_schema. اختلاف hero_stage
و featured_products با قرارداد مورد انتظار آشکار شد. اصلاح قرارداد/برنامه نیازمند
بررسی مستقل دامنهٔ فروشگاه‌ساز است؛ توقع تست‌ها برای سبزشدن تغییر نکرد.

۴. سه Known Failure دیگر هنوز امضای تأییدشده ندارند: تست هم‌زمانی کوپن روی
PostgreSQL و دو تست محتوای دمو. شناسهٔ آن‌ها به‌تنهایی CI را عبور نمی‌دهد.

۵. اجرای کامل همهٔ tierهای برنامه و اجرای GitHub Actions انجام نشده است.
اتصال GitHub موجود نامعتبر بود و مالک ادامهٔ کار صرفاً محلی را دستور داد؛ هیچ Push
یا Run ID جدیدی وجود ندارد. فعال‌سازی reviewers/branch protection/Secrets و
بررسی سازگاری واقعی سرور نیز انجام نشده است.

۶. بکاپ مقصد محلی و دادهٔ ساختگی داشت؛ مقصد off-site، append-only، کلید بازیابی
مستقل، RPO/RTO و تداخل منابع با RastiService.ir هنوز نیازمند آزمون محیط آزمایشی‌اند.

## تصمیم آمادگی

چهار نقص بحرانی اصلاح و تست شده‌اند. نسخه برای **بازبینی مستقل تغییرات و اجرای
آزمایش‌های ایزولهٔ بیشتر** آماده است؛ **مجوز فعال‌سازی staging مشترک یا Production
نیست**. پیش از فعال‌سازی، موانع امنیتی/مالی/تست و تنظیمات محیط باید بسته شوند و
CI واقعی همین commit اجرا شود. انتشار بدون قطعی در این تغییر پیاده‌سازی نشده است.
