# V5 — انعطاف‌پذیری چیدمان موتور R4 (ماتریس قابلیت‌ها)

معیار: «آیا می‌توان قالب هفتم با چیدمان کاملاً متفاوت را بدون تغییر کد برنامه ساخت؟» — همهٔ ردیف‌های زیر از داخل Design Studio
(Inspector و ابزار ساختار) و با قابلیت‌های عمومی R4 انجام می‌شوند؛ هیچ Recipe، کلید قالب یا CSS مخصوص سایت لازم نیست.

| نیاز | قابلیت عمومی R4 | کجا در Studio |
|---|---|---|
| چهار کاشی متناوب (متن/عکس) با عرض‌های نامساوی | چیدمان «چهارستونه» + `container.resize` (spans) + بلوک‌های `rich_text`/`linked_image` در خانه‌ها | ساختار ← اندازه ستون‌ها |
| تعداد، ترتیب، اندازه و نسبت خانه‌ها (دسکتاپ) | پریست‌ها/سفارشی تا ۴ خانه روی شبکهٔ ۱۲‌تایی؛ فاصله، هم‌ارتفاعی، تراز عمودی؛ طراحی «نسبت تصویر» (مربع، ۳:۲، ۱۶:۹، ۲۱:۹، پنل، عمودی…) | ساختار + ظاهر |
| چیدمان مستقل موبایل (چهار کارت ← اسلایدر تک‌کارتی) | ظاهر ← «چیدمان موبایل» (`mobile_layout`: اسلایدر / اسلایدر دوکارتی / زیر هم)؛ تنظیم چیدمان: ترتیب موبایل (معکوس) و حالت «اسلایدر» برای خانه‌ها | ظاهر / تنظیمات چیدمان |
| هیرو: نسبت، سمت تصویر، سهم ستون‌ها، پنل‌های کناری و گرادیانی | `image_side` و `split_ratio` هیرو + چیدمان «۶۷/۳۳» با هیرو و `multi_banner` پنل‌دار در یک خانه + پس‌زمینهٔ گرادیانی/پترن | بخش هیرو / ساختار |
| محل عمودی محتوا در بخش بلند | ظاهر ← «جای عمودی محتوا» (`valign`) برای متن/عکس | ظاهر |
| فوتر: چیدمان ستون‌ها، فاصله‌ها، ترتیب اجزا | هندسهٔ فوتر: `column_count`، `column_gap`، `order_about/links/categories/contact`، فاصله‌های عمودی (فقط برای قالب‌هایی که آن را رسم می‌کنند) | فوتر ← ابعاد |
| صفحهٔ محصول: گالری + پنل خرید | `gallery_position`, `gallery_split`, `thumbs_position`, `gallery_frame`, `info_panel` و فهرست قابل‌ترتیب `info_order` (قیمت، گزینه‌ها، مشخصات، هدیه، دکمه‌ها، یادآوری‌ها، تماس، اعتماد) | بخش product_main |

همهٔ مقادیر پراکنده (sparse) و پیش‌فرض‌خاموش‌اند: فروشگاهِ بدون تغییر، دقیقاً مثل قبل رندر می‌شود. هیچ Model/Migration تغییر نکرده است.

## اشکال‌های واقعی که این دور از روی تصویر پیدا و رفع شد
1. `valign` داخل ردیف هم‌ارتفاع/ارتفاع دستی اعمال نمی‌شد (محتوا بالا می‌ماند) ← قاعدهٔ `.rsec[data-d~="valign"]>.section`.
2. «نسبت تصویر» برای `linked_image` در ردیف هم‌ارتفاع نادیده گرفته می‌شد (عکس بلند ردیف را کش می‌داد) ← قاب صاحب جعبه است و تصویر آن را پر می‌کند.
3. ترتیب ستون فوتر وقتی فقط یکی تنظیم شده بود ستون‌های دیگر را جلو می‌انداخت ← بقیه جای طبیعی خود را نگه می‌دارند.

## محدودیت‌ها (صادقانه)
* حداکثر ۴ خانه در هر ردیف (ردیف‌های بیشتر = چند چیدمان زیر هم)؛ شبکهٔ دلخواه با بیش از ۴ ستون در یک Container ممکن نیست.
* ترتیب و تعداد ستون‌ها فقط برای فوترهای شبکه‌ای (stationery، marketplace_dense، premium، beauty، chocolate، dark_tech، promo) در Inspector عرضه می‌شود؛ فوترهای تک‌ستونی/مرکزی این کنترل را ندارند.
* اسلایدر موبایل «اسکرول افقی با snap» است (بدون فلش و نقطه).
