# ابزارهایِ QAِ پنلِ مالک (مرجع؛ در CI اجرا نمی‌شوند)

اجرا روی پایگاه‌دادهٔ **موقت** (هرگز production):

1. `ux_seed.py` — داده‌یِ QAِ ساختگی (فروشگاه/کاربر/فاکتور/…): `manage.py shell -c "exec(open('ux_seed.py').read())"`
2. `ux_crawl.js <port> <outdir> <label> [all|key]` — همه‌یِ صفحه‌هایِ GET در ۵ عرض (۱۴۴۰/۱۲۸۰/۷۶۸/۳۹۰/۳۲۰): وضعیت، overflow، خطایِ JS/کنسول، تعدادِ sidebar، فیلدِ عددیِ دارایِ فلش، ارتفاعِ دکمه‌ها، style درون‌خطی + اسکرین‌شات.
3. `ux_behavior.js` — ۲۳ بررسیِ رفتاری در مرورگر (منویِ موبایل، تأییدِ عملِ مخرب، dialog، toast، هشدارِ تغییرِ ذخیره‌نشده، اعتبارسنجیِ خطِ‌به‌خط، فیلدِ عددی، htmx).
4. `gen_route_audit.py` — تولیدِ `ROUTE_AND_UX_AUDIT_20261105.md` از `platform_admin_urls.py` + اندازه‌گیریِ خزشِ «قبل».

مسیرهایِ `/tmp/rs_reg/*` و پورت‌ها مالِ محیطِ ابری است؛ برایِ محیطِ ویندوزِ خودتان تغییر دهید.
