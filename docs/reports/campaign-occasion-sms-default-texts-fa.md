# متن‌های پیش‌فرض پیامک کمپین و مناسبت (برای تأیید)

> این متن‌ها فقط توسط مدیران راستی‌سی (پنل ادمین پلتفرم ← پیامک ← قالب‌ها و الگوها) قابل تغییرند. فروشنده فقط ارسال پیامک را روشن/خاموش می‌کند و پیش‌نمایش فقط‌خواندنی می‌بیند.
> داخل `{}` متغیرهای خودکار هستند. نمونه‌ی رندر با داده‌ی فرضی نوشته شده؛ «تعداد کاراکتر» بر اساس همان نمونه است (هر ۷۰ کاراکتر ≈ یک اعتبار پیامک).

**متغیرها:** `{customer_name}` نام مشتری · `{shop_name}` نام فروشگاه · `{occasion_name}` نام مناسبت · `{campaign_name}` نام کمپین · `{discount_code}` کد تخفیف · `{discount_amount}` مقدار هدیه (۱۵٪ / ۱۰۰٬۰۰۰ تومان / ارسال رایگان) · `{discount_expires_at}` مهلت استفاده (از اعتبار واقعی کد) · `{days_left}` روز مانده

> قالب‌های «فقط تبریک» عمداً متغیر کد/هدیه ندارند و افزودن آن‌ها در پنل ادمین رد می‌شود.
