# اسکرین‌شات‌هایِ تعرفه (۲۰۲۶-۱۱-۰۵)

Chromium روی یک پایگاه‌داده‌ی موقتِ PostgreSQL با **داده‌ی ساختگیِ QA** (سه پلنِ Base/Advanced/Ultra با اعدادِ نمونه؛ تصمیمِ مالک نیست و در کد/مهاجرت نیست). فونتِ Vazirmatn بارگذاری و تأیید شده است.

| پیشوند | محتوا |
|---|---|
| `plans-{1440,1280,768,390}-top/full/yearly` | صفحه‌ی عمومیِ `/plans/` (بالایِ صفحه، کل صفحه، دورهٔ سالانه) |
| `plans-390-matrix-*` | مقایسه‌ی موبایل (تبِ پلن) |
| `admin-plans-*` | فهرستِ پلن‌ها در Platform Admin |
| `admin-plan-form-*` | فرمِ یکپارچه‌ی پلن (دوره‌ها/تخفیف/تریال/بازاریابی/سقف‌ها؛ کلیدهایِ اعمال‌نشده غیرفعال) |
| `admin-pricing-content-*` | محتوایِ صفحه‌ی تعرفه: ردیف‌هایِ ماتریس، FAQ، خدماتِ اختیاری، گزارشِ شکاف |
